## Что сделать

Компоненты в `src/ui/` — каждый: `Component.tsx` + `Component.module.css` + `Component.test.tsx` (Vitest + @testing-library/react, добавь как devDeps). 1. **Button** (§6.1) — варианты primary / secondary / ghost / disabled через проп `variant`; высота 48/40 (`size: "md" | "sm"`), загрузочное состояние (`loading` — тот же размер, текст → индикатор, остаётся disabled); иконка слева (слот).
2. **Chip** (§6.2) — неактивный/активный, опциональный счётчик («Щука · 12»); ряд чипов = обёртка `ChipRow` с горизонтальной прокруткой.
3. **CatchCard** (§6.3 + §7.2) — медиа-зона (фото или заглушка-плитка вида 16:9), строка вида+вес, метаданные через «·», бейдж синхронизации (слот/проп), опционально бейдж «Трофей».
4. **SpeciesTile** (§6.4) — 1:1, чередование `--color-tint-blue`/`alt` по позиции (проп `variant`), иконка вида + подпись, выбранное состояние (проп `selected`: граница 2px primary, фон surface).
5. **Stepper** (§6.5) — «−»/значение+единица/«+», кнопки 44×44, пустое значение «—», ошибка диапазона цветом `--color-amber-text`; табличные цифры. Долгое нажатие/ускорение — НЕ делай (этап-агностик, MVP каркаса), фиксируй в отчёте как отступление от §6.5 сознательное.
6. **OfflineBanner** (§6.6).
7. **WeatherLine** (§6.8 + §7.3) — состояния: данные / «Погода не записана» / загрузка (скелетон).
8. **FloatInput** (§6.9) — поле с плавающим лейблом (пустое: лейбл внутри; фокус/заполнено: лейбл поднимается, уменьшается, `--color-primary-deep-text`; фокус: граница primary + `--focus-ring`; ошибка: амбер-граница + текст; disabled; вариант textarea от 96px). Реализация на чистом CSS+HTML (input + label, псевдоклассы), без менеджера форм.
9. **TabBar** (§6.10) — 4 пункта, активный/неактивный, центральный «Запись» — кнопка-круг 56px primary, safe-area `env(safe-area-inset-bottom)`, бейдж-счётчик (точка 8px / число). Требует React Router Link — добавь react-router-dom.
10. **SyncBadge** (§6.11) — состояния pending/syncing/synced/error (tap-зона «Повторить» 44px, проп `onRetry`).

**Иконки:** тонкие линейные inline-SVG (толщина штриха 1.5, размеры 16/20/24, `currentColor`) в `src/ui/icons/` — минимальный набор, который нужен компонентам: fish (для плиток/заглушек, один дефолтный), camera, trophy, cloud (погода), wifi-off, clock/часики (ожидание), check, home/feed, map-pin, pencil, plus, minus, chevron.

# Справочник видов рыбы

Реализация решения [ADR-0009](adr/0009-species-catalog.md). Источник истины — сид-миграция [supabase/migrations/0001_species.sql](../supabase/migrations/0001_species.sql).

## Принципы

- **51 вид средней полосы РФ** на MVP: имя (RU) + латинское имя + семейство + флаг хищника + код иконки.
- **Id детерминированы** из латинского имени (`uuid` из md5) — одинаковые id в local/staging/production и в клиентском кэше.
- Пополнение — только миграциями (`on conflict (name_ru) do nothing` — повторный прогон безопасен).
- Клиент — только `select`; RLS-политика разрешает чтение всем аутентифицированным, запись имеет лишь service role.

## Флаг «хищник» (`is_predator`)

Проставлен для рыб, чьё меню в значительной мере — мальки и рыба (важно для будущей аналитики по приманкам): щука, окунь, судак, берш, носарь, сом, налим, ротан, голавль, жерех, лосось, обе форели, корюшка, угорь. Всеядные (язь, ёрш, канальный сомик) помечены `false` — ловятся и на «мирные» насадки.

## Что сознательно не вошло (добавим по заявкам миграцией)

- Морские и южные виды (камбала, ставрида, тарань, рыбец каспийский и т.п.) — если аудитория этапа 1 начнёт ловить на юге/море.
- Гибриды и редкие интродуценты (буффало, веслонос, веслоногие сомики).
- Краснокнижные исключения: в списке есть стерлядь и подуст — во многих регионах ловля ограничена; UI этапа 2 покажет предупреждение (данные — отдельной таблицей ограничений).

## Иконки

`icon` — текстовый код (`pike`, `zander`, `perch`, `carp`, `catfish`, `trout`, `eel`, ...), дефолт `fish`. Клиент мапит код → векторная иконка/эмодзи в дизайн-системе; пополнять набор иконок можно без миграций БД.

# ADR-0003: React + Vite + TypeScript

- **Статус:** Принято
- **Дата:** 2025-09-22

## Контекст

Нужен мобильный-first PWA: много форм, списков, карт, оффлайн-логика. Команда малая, важны скорость разработки, экосистема (готовые PWA/оффлайн-решения) и типобезопасность предметной модели.

## Решение

**React 18+ + Vite + TypeScript**. Сопутствующие выборы (детали, не отдельные ADR):

| Область | Выбор |
|---|---|
| Роутинг | React Router — зафиксировано 2025-09-22 при планировании каркаса: зрелый, предсказуемый, для 8 экранов PWA достаточно |
| Серверное состояние | TanStack Query (кэш, retry, invalidation) |
| Локальный UI-state | Zustand (минимальный бойлерплейт) |
| IndexedDB | Dexie (типизация, hooks, liveQuery) |
| Стили | CSS Modules — зафиксировано 2025-09-22 при планировании каркаса: токены дизайн-системы уже CSS-переменные, стили макетов переносятся напрямую, ноль новых зависимостей |
| Формы | React Hook Form + zod-валидация |
| Тесты | Vitest + Testing Library |
| PWA | vite-plugin-pwa (Workbox под капотом) |

## Альтернативы

- **Vue 3 + Vite** — сопоставим; выбран React ради большего пула готовых решений и найма на этапе публичного продукта.
- **Svelte/SvelteKit** — минимальный бандл и отличный мобильный рантайм, но меньше готовых интеграций (Workbox-обвязки, Dexie-хуки) и риск на этапе найма.

## Последствия

### Позитивные
- Зрелые инструменты для каждой задачи из таблицы; типы сквозь data-слой до UI.
- Vite: быстрые dev-сервер и сборки; vite-plugin-pwa снимает рутину манифеста/воркера.

### Негативные / риски
- Больше бойлерплейта, чем у Svelte; дисциплинируем стилем слоёв из [02-architecture.md](../02-architecture.md).

### Нейтральные
- React 19/новые API — миграция несущественна для MVP.

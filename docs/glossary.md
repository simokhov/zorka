# Глоссарий

| Термин | Значение |
|---|---|
| **Поимка (Catch)** | Одна запись улова: вид, параметры, контекст (место, время, погода), фото |
| **Выезд (Trip)** | Поездка на рыбалку целиком; группирует поимки (этап после MVP) |
| **Место (Place)** | Сохранённая именованная точка ловли |
| **Справочник видов (Species)** | Глобальный каталог видов рыбы, поддерживаемый командой |
| **Трофей** | Лучший экземпляр вида по весу/длине у пользователя |
| **Outbox** | Локальная очередь записей, созданных без сети, ожидающих синхронизации |
| **Sync engine** | Модуль клиента, досылающий outbox и обновляющий кэш при появлении сети |
| **Обогащение погодой** | Автоматическое приложение снимка погоды к поимке в момент её создания |
| **OWM** | OpenWeatherMap — погодный API (ADR-0006) |
| **RLS** | Row Level Security — построчная изоляция данных в Postgres по `user_id` |
| **PWA** | Progressive Web App — веб-приложение с установкой, оффлайн-кэшем и иконкой на экране |
| **Edge Function** | Серверная функция Supabase; единственная точка доступа к внешним API |
| **Мягкое удаление** | Запись помечается `deleted_at` и попадает в корзину, физически удаляется позже |
| **Зорька** | Утренняя заря, время лучшего клёва; имя продукта |
| **Дневник рыбака** | Подзаголовок экрана входа; описывает суть продукта, не является названием |
